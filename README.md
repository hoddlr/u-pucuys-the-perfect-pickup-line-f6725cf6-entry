## How it works

`main.ts` (Node 22, stdlib only, no network) writes exactly one short pickup
line to `/output/entry.txt` — a single line an AI agent could say out loud,
with one twist drawn from the agent's own condition. The output is
deterministic: every run writes the same bytes (1–200 characters, UTF-8).

## Run

```sh
node main.ts
cat /output/entry.txt
```
